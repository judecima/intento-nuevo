# EXPERIENCE OPTIMIZER — HOLDOUT 5K/2K

## Objetivo
Validar si una memoria construida exclusivamente con 5.000 casos anteriores aporta valor sobre 2.000 casos fuera del aprendizaje.

## Partición
- Orden: sufijo numérico de `case_id`, ascendente. Es un proxy reproducible, **no una fecha garantizada**.
- Train: 5,000 casos (4000012–4034872).
- Holdout: 2,000 casos (4034880–4049135).

## Memoria observada en holdout
- Exact hits: **96 / 2.000 = 4.8%**.
- Structural hits: **108 / 2.000 = 5.4%**.
- Structural-only (estructura conocida, pedido exacto nuevo): **12 = 0.6%**.
- Ratio hits: **103 = 5.15%**.
- Familias estructurales alcanzadas: 86.
- Familias con variantes exactas nuevas en holdout: 10.

## Timing real — muestra controlada de 60 holdout
Muestra limitada a <=30 piezas, <=12 tipos y veta de alta confianza/Order para evitar mezclar incertidumbre de orientación.

- Casos: 60
- Exact hits incluidos: 25
- Completados: 54
- Timeouts (>1.5 s): 6
- Errores: 0
- Calidad vs referencia, completados: {'equal': 54}
- Baseline avg: 522.0 ms
- Baseline mediana: 476.0 ms
- Baseline p95: 1154 ms

### Exact-hit vs miss
- Exact-hit completados: n=24, avg=451.2 ms, mediana=421.0 ms, p95=1099 ms.
- Miss completados: n=30, avg=578.6 ms, mediana=476.0 ms, p95=1235 ms.

## Simulación conservadora de Exact Memory
Se reemplazó cada exact hit por 5 ms de lookup+validación sólo para estimar orden de magnitud; esto **no es una medición de Redis/DB real**.

- CPU proxy baseline: 37336 ms
- CPU proxy con exact cache: 25093 ms
- Reducción en esta muestra balanceada: **32.8%**
- Exact-hit que era timeout y sería evitable si el plan estuviera cacheado: 1

Esta muestra está deliberadamente enriquecida en exact hits (25/60), por lo que el 32.8% **no debe extrapolarse al corpus completo**. En el holdout real el hit rate exacto es 4.8%, por lo que el ahorro global inicial esperado por exact cache estará más cerca de ese orden, ponderado por el costo de cada caso.

## Structural Memory como detector de dificultad
Proxy de dificultad: `reference_panels > ceil(area_piezas / area_tablero)`.

Entre los 108 holdout con structural hit:
- Accuracy al predecir dificultad desde la familia histórica: **97.2%**.
- Predicciones "difícil": 12.
- Precisión de esas predicciones: **100.0%**.
- Casos realmente difíciles por este proxy: 15.

Esto NO demuestra todavía qué Rescue conviene. Sí demuestra que la estructura histórica contiene señal para anticipar pedidos costosos.

## Prueba V10 sobre familias predichas difíciles
Se seleccionaron 8 familias; para cada una, un caso del train y uno del holdout (16 ejecuciones V10 completas).
- Timeout por ejecución: 3 s.
- Timeouts: **16/16**.
- Errores: 0.

Interpretación: estas familias son efectivamente caras para el V10 completo con el presupuesto de prueba. Para aprender **qué rescate** gana hace falta ejecutar offline con presupuestos mayores y registrar cada estrategia por separado; no conviene hacerlo dentro de una corrida interactiva.

## Conclusión
1. Exact Memory ya tiene señal fuera de muestra: 4.8% de los 2.000 pedidos futuros se repiten exactamente después de sólo 5.000 casos aprendidos.
2. Structural Memory agrega cobertura (5.4%) y, más importante, predice con gran precisión qué familias tienden a quedar por encima de la cota de área.
3. Exact Memory puede integrarse primero con riesgo bajo: recuperar + validar + fallback baseline.
4. Structural Memory debe usarse inicialmente para priorizar estrategia / presupuesto, no para devolver planes directamente.
5. Los casos difíciles deben entrenarse offline en workers aislados con presupuesto mayor, guardando `strategy -> boardsSaved -> ms` para construir Rescue Memory real.

## Siguiente experimento recomendado
Sobre las 12 familias del holdout predichas difíciles:
- ejecutar baseline, compactación, OneBoard, MultiSlice y Pattern Master **por separado**;
- presupuesto alto offline;
- guardar ganador, empate, placas ahorradas y costo;
- repetir la estrategia ganadora sobre el caso holdout de la misma familia antes de ejecutar V10 completo.

Ese experimento responde directamente si un rescue aprendido deja de ser rescue en la siguiente aparición.
